A responsive portfolio website built with HTML, CSS and vanilla JavaScript.

6. Add employer names, employment dates and a resume link only after verifying the details.

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Publish with GitHub Pages
1. Create a public repository named `ankita-portfolio` (or your preferred repository name).
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After deployment, GitHub Pages will show your live website URL in the Pages section.

## Important
Do not upload employer/client source code, credentials, private data, customer details or confidential screenshots. Use only sanitized demonstrations that you own or are authorized to publish.
